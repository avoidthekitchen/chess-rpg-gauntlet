# Original game archive and reference

The owner saved the original Pawnshire game at [alpha](https://unformedideas.com/alpha-chess-rpg/).
The accepted curriculum is live at [production](https://unformedideas.com/chess-rpg/); [staging](https://unformedideas.com/staging-chess-rpg/) previews later changes.
The owner confirmed this production direction on 2026-10-24.

The alpha preserves the original game and provides a useful reference for its storybook presentation:

- Painted maps and winding routes.
- Animal tokens, portraits, and piece movement.
- Companion voices, introductions, and conversation history.
- Short celebrations and responsive board layouts.

Current presentation follows the [art direction](design/art.md), [voice guide](design/story.md#voice-and-dialogue), and [playbook](playbook.md).
The `legacy-*` documents preserve the earlier design, including its implemented features, proposals, and unfinished TODOs.
Those documents do not establish that every proposed army, economy, power, faction AI, or custom-battle feature was built.
Those systems remain deferred in the production curriculum.

The legacy documents’ old approval requirements and engine benchmarks are historical, not current merge or release gates.
Historical results remain unchanged. [Legacy retirement](legacy-retirement.md) links the removed code and technique references at an immutable revision.
The [decisions](design/decisions.md) and [release record](complete-journey-release.md) describe the accepted scope and current evidence.
Routine deployments target production or staging through the documented commands.

The owner accepted 393×852 WebKit emulation for the current release check because no physical device was available.
No physical-device coverage is claimed; a physical test is not a release blocker.
